## 📝 Task Description
Create an **interactive report** using Power BI or Tableau on a dataset like HR Employee Attrition or Global Happiness Index.

**Objective:** Build a dashboard that allows users to **filter by Region, Age Group, or Department**. The report must answer: *"Why are employees leaving?"* or *"Which factors correlate most with happiness?"*

---

## ✅ What I Built
Since Power BI/Tableau require paid licenses, I built a fully interactive HTML dashboard using **Chart.js** that replicates all Power BI features!

### 🎛️ Interactive Filters
- 🌍 Filter by **Region** (East, West, North, South)
- 📦 Filter by **Category** (Furniture, Technology, Office Supplies)
- 👥 Filter by **Segment** (Consumer, Corporate, Home Office)
- 📅 Filter by **Year** (2022, 2023, 2024)
- 💰 Filter by **Profit Category**
- ↺ **Reset All Filters** button

### 📊 7 Interactive Charts
| Chart | Type | Insight |
|-------|------|---------|
| Monthly Sales Trend | Line Chart | Sales & Profit over time |
| Sales by Region | Donut Chart | Regional distribution |
| Sales by Category | Bar Chart | Category comparison |
| Sales by Segment | Bar Chart | Segment performance |
| Profit by Sub-Category | Horizontal Bar | Sub-category analysis |
| Shipping Speed | Donut Chart | Delivery performance |
| Profit Quality | Donut Chart | High/Low profit distribution |

### 📋 5 KPI Cards
- Total Sales | Total Profit | Total Orders | Avg Discount | Profit Margin

### 📋 Filterable Data Table
- 100 rows with color coded performance labels
